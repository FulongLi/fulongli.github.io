# Website styling

- Keep the existing site palette, typography, content width, spacing and shared layouts when adding or revising pages.
- Source documents and presentation decks provide content and evidence, not a new visual theme. Do not copy their colours or decorative layouts into the website.
- Use the shared theme for headings, paragraphs, links, tables, figure captions and disclosure sections. Do not introduce page-specific colour, font-size or page-width overrides unless the user explicitly requests them.
- Page-specific CSS may handle technical needs such as image aspect ratios, table overflow and anchor offsets without changing the site's visual style.
- Preserve the colours and proportions within original source images and simulation plots.
