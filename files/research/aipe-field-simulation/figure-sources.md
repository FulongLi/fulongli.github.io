# AIPE Field Simulation figure sources

## Example figures

The three figures are copied without cropping, recolouring or resizing from the [AIPE-Field-Simulation heat-sink example](https://github.com/FulongLi/AIPE-Field-Simulation/tree/main/examples/heatsink_to247/results/figures) (commit `e52fb36`, 28 October 2026). They were generated by the example script in the repository's continuous-integration run named in [the example report](https://github.com/FulongLi/AIPE-Field-Simulation/blob/main/examples/heatsink_to247/results/report.md).

| Published asset | Repository file |
| --- | --- |
| `/images/research/aipe-field-simulation/heatsink-geometry-mesh.png` | `examples/heatsink_to247/results/figures/1_geometry_and_mesh.png` |
| `/images/research/aipe-field-simulation/heatsink-temperature.png` | `examples/heatsink_to247/results/figures/2_temperature_3d.png` |
| `/images/research/aipe-field-simulation/heatsink-mesh-convergence.png` | `examples/heatsink_to247/results/figures/5_mesh_convergence.png` |

Inputs, results and verification values are taken from [the example README](https://github.com/FulongLi/AIPE-Field-Simulation/blob/main/examples/heatsink_to247/README.md) and report. Benchmark accuracy is taken from [the validation record](https://github.com/FulongLi/AIPE-Field-Simulation/blob/main/docs/validation.md), and the workflow role from [the AIPE-Workflows DAB workflow](https://github.com/FulongLi/AIPE-Workflows/blob/main/workflows/converter_dab/README.md), accessed on 28 October 2026.
